Privacy Policy

YouTube Remaining Time (Speed) · Last updated: September 19, 2026

Overview

YouTube Remaining Time (Speed) (“the Extension”) is a Chrome browser extension that runs on YouTube pages and updates the right-side player duration text to show total video length divided by the current playback speed.

Data collection

The Extension does not collect any user data.

  • No personal information
  • No browsing history beyond local on-page DOM updates
  • No analytics, advertising, or tracking
  • No accounts, cookies, or identifiers created by the Extension
  • No data is stored, sold, shared, or transmitted to any server

Permissions

The Extension only accesses YouTube (youtube.com / www.youtube.com / m.youtube.com) so it can modify the on-page player duration display. It does not access other websites.

Remote code

The Extension does not use remote code. All logic is included in the packaged extension files.

Children’s privacy

The Extension does not knowingly collect any information from anyone, including children.

Changes

If this policy changes, the “Last updated” date above will be revised. Continued use of the Extension after changes means you accept the updated policy.

Contact

For privacy questions about this Extension, contact the publisher through the Chrome Web Store listing support email / contact details.
